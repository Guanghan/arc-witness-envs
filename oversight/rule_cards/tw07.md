# tw07 — EraserLogic

Draw a path that partitions the grid; within **each** region, the number of **erasers** must equal the number of **constraint violations** in that region. Each eraser absorbs exactly one violation (from squares / stars / triangles). A region with zero erasers must be fully valid; a region with K erasers must contain exactly K violations.

Core knowledge: Meta-reasoning — error balancing / absorption.
