# tw13 — EraserAll

Generalization of tw07: within **each** region, the number of **erasers** must equal the number of **violations**, where violations may now come from squares, stars, triangles, **and** tetris (a failed exact cover counts as a violation). Hexagon dots remain a **hard** constraint — all dots must be visited regardless of erasers.

Core knowledge: Meta-reasoning — generalized error absorption.
